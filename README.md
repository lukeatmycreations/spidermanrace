# 🕷️ Spider-Man Race! (Spider-Man: NYC Web Swinger)

A fast-paced HTML5 physics-based web-swinging game where you race against Miles Morales through the skyscraper alleys of New York City! Built entirely with HTML5 Canvas and JavaScript.

## 🚀 Live Demo
**[👉 Click Here to Play Spider-Man Race Live!](https://lukeatmycreations.github.io/spidermanrace/)**

*(Note: Replace `YOUR-GITHUB-USERNAME` in the repository settings with your actual GitHub username to activate this link!)*

---

## 🎮 Game Controls
*   **`W` Key (Hold)**: Swing & Reel In (Hold down to swing higher and gain momentum).
*   **`▲` Up Arrow**: Extra Web Pull / Air Jump.
*   **`▼` Down Arrow**: Fast Dive Down (Gain speed rapidly).
*   **`◄` / `►` Left/Right Arrows**: Air Steering & Acceleration.
*   **`Mouse Click`**: Click anywhere on the screen at start to enable Game Audio & Music!

---

## 🌟 Game Features
*   **3 Iconic Maps**: 
    *   🏙️ **Midtown Manhattan**: Dense skyscraper alleys littered with floating drones.
    *   🌳 **Central Park & Playground**: Green grass, trees, playgrounds, and flying pigeons.
    *   🌃 **Cyber-NYC 2099**: A futuristic synthwave skyline filled with neon hover discs.
*   **Dynamic Wardrobe**: Unlock up to **100 unique Spider-Suits** by beating Miles Morales in races!
*   **Multiple Difficulties**: From *Super Easy (Very Very Very Slow)* up to *Hard (Fast)*.
*   **Real-time HUD**: Tracks your speed (MPH), distance left to finish (10,000 FT target), race time, and your personal best records.

## 🛠️ GitHub Repository Requirements
To ensure this game loads correctly on GitHub Pages, make sure your files look exactly like this:
1. Ensure your core game code is named **`index.html`** (all lowercase) and placed directly in the main folder of your repository.
2. Ensure your images, sound clips, or external assets are referenced using **relative paths** (e.g., `src="assets/sound.mp3"` instead of absolute C:\ drive paths) so the web server can read them.
